# GuardianBand: Central Backend Server

This is the core **Node.js, Express & Socket.IO real-time backend engine** (Port `5000`).

## 🎯 Role
Run this on the laptop designated as the **Central Host / Server**.

## 🚀 How to Run

1. Make sure all teammates are connected to the same **Wi-Fi router or mobile hotspot**.
2. Double-click **`GET_MY_IP.bat`** to find your laptop's IP address (e.g. `192.168.1.15`).
3. Give that IP to your teammates so they can run `SET_BACKEND_IP.bat` on their laptops.
4. Double-click **`START_BACKEND_SERVER.bat`** to launch the server!

### Manual Terminal Commands
```bash
npm install
npm start
```
Health Check: [http://localhost:5000/health](http://localhost:5000/health)
