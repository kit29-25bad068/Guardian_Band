# GuardianBand: Wearable Device Simulator

This is the standalone **Wearable Device Simulator** web application (Port `5176`).

## 🎯 Role
Run this application on the laptop designated for the **Wearer / Smartwatch Device Simulator**.

## 🚀 How to Run on This Laptop

### Step 1: Connect to Backend (if running across multiple laptops)
- If your teammate is running the Backend Server on another laptop, double-click **`SET_BACKEND_IP.bat`** and enter their laptop's Wi-Fi IP address (e.g. `192.168.1.15`).
- If you are running the backend on this same laptop, you can skip this step (it defaults to `localhost`).

### Step 2: Launch the Website
- Double-click **`START_DEVICE_SIMULATOR.bat`**
- It will install dependencies on first run and open **http://localhost:5176** in your browser!

### Manual Terminal Commands
```bash
npm install
npm run dev
```
Open [http://localhost:5176](http://localhost:5176) in your browser.
