# GuardianBand: Guardian & Wearer Safety Portal

This is the standalone **Guardian & Wearer Safety Portal** web application (Port `5175`).

## 🎯 Role
Run this application on the laptop designated for the **Guardian / Family Member / Wearer**.

## 🚀 How to Run on This Laptop

### Step 1: Connect to Backend (if running across multiple laptops)
- If your teammate is running the Backend Server on another laptop, double-click **`SET_BACKEND_IP.bat`** and enter their laptop's Wi-Fi IP address (e.g. `192.168.1.15`).
- If you are running the backend on this same laptop, you can skip this step (it defaults to `localhost`).

### Step 2: Launch the Website
- Double-click **`START_GUARDIAN_PORTAL.bat`**
- It will install dependencies on first run and open **http://localhost:5175** in your browser!

### Manual Terminal Commands
```bash
npm install
npm run dev
```
Open [http://localhost:5175](http://localhost:5175) in your browser.
